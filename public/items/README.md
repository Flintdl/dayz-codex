# Imagens dos Itens

Coloque PNGs aqui usando a convenção: `<slug>.png`

Exemplos:
- `m4-a1.png`
- `tuna-can.png`
- `plate-carrier.png`

Tamanho recomendado: **256×256** (transparente).

Se um arquivo não existir, o site usa o ícone Flaticon do campo `icon` como fallback automático.

## Baixar em massa

Use o script para puxar do Fandom Wiki:

```bash
bash scripts/fetch-item-images.sh
```
